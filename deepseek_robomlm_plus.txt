Displacement_velocity = Displacement_net / n

text

Behavior State Classification:

text
BREAKOUT:   F_ratio > 1.2 AND O_ratio < 0.8
PULLBACK:   F_ratio < 0.8 AND O_ratio > 1.2

UNKNOWN:    Otherwise

text

7. MSDL ENGINE (Code Standard Example)
Weighted Depth:

text
L_depth_raw = Σ (BidVolume_i + AskVolume_i) * exp(-γ * level_i)
Bid/Ask weighted depth:

text
B_w = Σ BidVolume_i * exp(-γ * level_i)
A_w = Σ AskVolume_i * exp(-γ * level_i)
Depth imbalance:

text
D_imbalance = (B_w - A_w) / (B_w + A_w)
Spread:

text
S = Ask_best - Bid_best
S_rel = S / Mid
Mid = (Ask_best + Bid_best) / 2
Spread liquidity:

text
L_spread = 1 / (1 + S_rel)
Observable liquidity:

text
L_obs = normalized_depth * L_spread
(Resilience excluded unless time-series data available.)
